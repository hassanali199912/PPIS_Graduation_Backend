2. نبذة عن المشروع والفكرة الأساسية

ما هو FekraTech؟

FekraTech منصة رقمية مصرية تساعد رواد الأعمال ورواد المشاريع الصغيرة والمتوسطة على إعداد دراسات جدوى احترافية بسرعة وتكلفة منخفضة باستخدام الذكاء الاصطناعي، مع تركيز على السوق المصري والقوانين المحلية (مثل قانون 152 لسنة 2020 ومتطلبات البنوك المصرية).

المشكلة التي نحلها

  • 70% من الشركات الناشئة المصرية تفشل خلال أول 24 شهر — غالبًا بسبب ضعف التخطيط وليس نقص التمويل فقط
  • دراسات الجدوى التقليدية تكلف من 15,000 إلى 50,000 جنيه وتستغرق 2–4 أسابيع
  • أدوات AI العالمية (ChatGPT) لا تفهم السياق المصري: أسعار، قوانين، سوق محلي

الحل الذي نقدمه

  • Wizard ذكي — 24 سؤالًا بالعربية في 5 مراحل (الهوية، السوق، التشغيل، المالية، المخاطر)
  • AI + RAG — توليد دراسة جدوى مخصصة مع سياق من بحث السوق المرفوع (PDF)
  • توليد شعار — إنشاء Logo للمشروع تلقائيًا حسب الهوية البصرية
  • Human-in-the-Loop — إمكانية طلب متخصص بشري (استشارة، بحث سوق، شعار يدوي)
  • تسليم سريع — دراسة جدوى كاملة في دقائق بدل أسابيع

الجمهور المستهدف

رواد الأعمال المصريين، طلاب الجامعات، أصحاب المشاريع الصغيرة والمتوسطة، ومن يريدون تحويل فكرة إلى دراسة جدوى جاهزة للعرض على البنوك أو MSMEDA.

4. الـ Features الموجودة في المشروع

4.1 نظام المستخدمين والمصادقة

  • تسجيل حساب جديد (اسم، بريد، كلمة مرور، هاتف اختياري)
  • تسجيل الدخول والحصول على JWT Token
  • عرض وتعديل الملف الشخصي (الاسم فقط — البريد والهاتف للعرض)
  • تغيير كلمة المرور (بالكلمة الحالية أو OTP)
  • إضافة رقم هاتف ثانوي عبر OTP (مرة واحدة فقط)
  • أدوار: user / admin / specialist

4.3 محتوى دراسة الجدوى (AI Output)

الـ AI يُرجع JSON منظمًا بالحقول التالية:

  • executiveSummary — الملخص التنفيذي
  • marketAndCustomersAnalysis — تحليل السوق والعملاء
  • competitorsAnalysis — تحليل المنافسين
  • operationsModel — نموذج التشغيل
  • marketingAndSalesPlan — خطة التسويق والمبيعات
  • costs.establishment / costs.operating — تكاليف التأسيس والتشغيل
  • revenueAndProfitOutlook — توقع الإيرادات والأرباح
  • risksAndMitigation — المخاطر وخطط التخفيف
  • recommendations — التوصيات
  • ninetyDayActionPlan — خطة 90 يوم

4.4 نظام RAG (Retrieval-Augmented Generation)

  • رفع PDF → استخراج النص → تقسيمه لـ chunks (500–1000 حرف)
  • تصنيف كل chunk: market / pricing / competitors / costs
  • عند توليد الدراسة: استرجاع أفضل 5 chunks ذات صلة وإضافتها للـ prompt
  • النتيجة: دراسة جدوى مبنية على بيانات السوق الفعلية وليس AI عام فقط

4.5 توليد الشعار (Logo Generation)

  • اختيار: اسم العلامة، الشعار النصي، نوع النشاط، الجمهور، الأسلوب، الألوان
  • توليد عبر Pollinations.ai وحفظ في uploads/logos/
  • Image Proxy لتجاوز مشاكل CORS في المتصفح

4.6 طلبات المتخصصين (Human-in-the-Loop)

  • MARKET_RESEARCH — طلب بحث سوق يدوي
  • MANUAL_LOGO — طلب تصميم شعار يدوي
  • CONSULTATION — طلب استشارة
  • حالات الطلب: PENDING → APPROVED / REJECTED / IN_PROGRESS → COMPLETED

4.7 لوحة الإدارة (Admin)

  • عرض كل المستخدمين مع عدد مشاريعهم
  • عرض كل المشاريع وتفاصيل أي مشروع

7. أسئلة متوقعة في Q&A (جهّزوا إجاباتها)

س: ليه اخترتوا MongoDB مش SQL؟
ج: البيانات فيها هيكل مرن (JSON للدراسة، arrays للإجابات، nested chunks) — MongoDB مناسبة لـ document-based data زي feasibilityResponse.
س: إيه الفرق بينكم وبين ChatGPT؟
ج: ChatGPT عام وما بيفهمش السوق المصري. FekraTech فيه Wizard منظم + RAG من PDF بحث السوق + output JSON جاهز للعرض على البنوك.
س: إزاي RAG شغال؟
ج: PDF → chunks → keyword scoring → أفضل 5 chunks تتضاف للـ prompt. مش vector embeddings حاليًا — scoring بالكلمات المفتاحية.
س: إيه الـ AI models المستخدمة؟
ج: OpenRouter (GPT-4o-mini) أساسي، Google Gemini 2.0 Flash بديل، Pollinations.ai للشعار.
س: البيانات بتتخزن فين؟
ج: MongoDB على السيرفر — مش localStorage. localStorage في الفرونت للـ token و projectId بس.
س: إزاي بتتعاملوا مع الأمان؟
ج: JWT + bcrypt، OTP hashed، rate limiting على OTP، Bearer token في كل request محمي.
س: Human-in-the-Loop يعني إيه؟
ج: المستخدم يقدر يطلب متخصص بشري (استشارة، بحث سوق، شعار) — AI + خبرة بشرية.
س: إيه Business Model؟
ج: Tiered pricing: Starter (automated) / Pro (AI + human review) / Growth (monitoring) — أرخص بكتير من الاستشارات التقليدية.
س: إيه التحديات اللي واجهتوها؟
ج: (جهّزوا إجابة حقيقية) — مثل: جودة output الـ AI، CORS مع Pollinations، validation الـ wizard، OTP delivery.
